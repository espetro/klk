## Flow 0A — Create Circle → Invite → Post Event → RSVP  (THE M1 loop)

[1-3 onboarding]  (new install)
  --next/next--> [4 city-select]
  --city picked--> [5 guest-or-keygen]
  --generate keys--> [6 events-home]

[6 events-home]
  --circles tab--> [10 circles-listing]

[10 circles-listing]
  --FAB (+)--> [11 circles-create-circle]
  --error: not signed in--> (alert: "Sign in to create a circle")

[11 circles-create-circle]
  --type name--> (Create Circle button enabled)
  --submit--> (spinner)
  --success--> (11a-circle-created-toast) --> [12 circles-selected-circle-main-view]
  --error: relay unreachable--> (alert: "Failed to create circle — check connection")

[12 circles-selected-circle-main-view]  (Events tab, empty state)
  --[Invite] button--> [18 circles-invite]
  --three-dot → manage--> [17 circles-admin]
  --"Create Event" / "+ New Event"--> [16 circles-create-event-from-circle]

[18 circles-invite]
  --paste npub/hex--> (Send Invite enabled)
  --"Copy Circle ID"--> (18a-circle-id-copied-toast)
  --Send Invite--> (spinner)
  --success--> (18a-invite-sent) --> [12 circles-selected-circle-main-view] (member count +1)
  --error: invalid pubkey--> (inline: "Invalid npub or public key format")
  --error: relay fail--> (alert: "Failed to invite — check connection")

[16 circles-create-event-from-circle]  (EventForm sheet)
  --fill title + dates--> (Publish to Circle enabled)
  --submit--> (spinner)
  --success--> [12 circles-selected-circle-main-view] (event appears in list)
  --error--> (alert: "Failed to publish event")

[12 circles-selected-circle-main-view]  (event card visible)
  --tap event card--> [13 circles-event-view]

[13 circles-event-view]  (event detail modal)
  --RSVP button ("Not Going" → tap)--> (8a-rsvp-confirm)
  --success--> (button label → "Going", attendee count +1)
  --error: relay fail--> (alert: "Failed to RSVP")

  ✓ M1 COMPLETE — circle created, member invited, event posted, RSVP recorded

## Known gaps to audit before M1 ships

- [ ] Circle create: no success toast (11a). Currently navigates silently.
- [ ] Invite send: no confirmation toast (18a). Sheet closes but no feedback.
- [ ] RSVP from circle event view: button state ("Not Going") is the initial state
       even for events you haven't RSVPed — confirm this is accurate, not a bug.
- [ ] Circle event view (13) shown via router.push(`/event/${e.id}`) — this goes to
       the PUBLIC event detail, not the private one. Verify correct screen is shown.
- [ ] EventForm in circle/[id].tsx references `values.start` / `values.end` but
       EventFormValues type uses `startDate` / `endDate` (see event/new.tsx).
       This is a likely runtime crash — audit type alignment.
- [ ] No error boundary around circle/[id].tsx — relay errors are swallowed silently.
- [ ] Invite sheet uses NDKMock (alias) for NDK type — confirm real NDK is passed
       through NDKContext correctly at runtime.
